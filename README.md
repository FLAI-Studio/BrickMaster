# 卡机砖家 (BrickMaster)
卡机砖家是一款模拟占用系统资源的恶搞小程序。不需要虚拟机、不需要压力测试工具，仅靠 `malloc` 疯狂申请内存，就能让你的任务管理器内存曲线瞬间"起飞"。属于"系统杀手"的入门简化版，仅供娱乐和学习研究。

本项目基于 Qt 6 开发，支持 `Windows` 和 `Android` 平台。

## 功能
- 双重免责确认（想跑？先签"生死状"）
- 10 秒倒计时反悔期
- 实时日志面板，显示已占用内存
- 自动停止保护，不会真的把系统搞崩

## 编译
1. 安装 Qt 6.x（勾选 MinGW 64-bit）
2. 打开 `Bricker.pro`
3. 构建 → 运行
